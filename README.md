## 低延迟由什么决定：距离、跳数、回程线路

三件事：物理距离、路由跳数、线路质量。香港离大陆近只解决了第一件。如果流量出了国际出口绕一圈再回来，物理距离再近也白搭——测评里出现过 ping 180ms 的“香港VPS”，traceroute 一查，流量绕道日本再回来，体验跟美西机器差不多。

线路名词不用背太多，大陆方向记住三组对应关系就够：电信回程看 CN2 GIA，联通看 AS9929，移动看 CMI。三网全优化的组合（比如 CN2 GIA + AS9929 + CMI 同时配齐的东京线路）属于最高一档，价格也最高，适合把大陆连通性当硬性要求的场景。

验证方法比名词更重要。下单前找商家要测试 IP 或 Looking Glass，本机 ping 只能看往返时间，traceroute 和 mtr 才能暴露路径有没有绕路。测的时候务必对比白天和晚高峰：北京时间 20 点到 23 点前后是东亚方向的拥堵时段，共享国际线路最容易在这个时间段露馅。公开实测记录里，走 CN2 GIA 的香港机器白天从广州电信测是 8–12ms，晚高峰涨到 15–20ms，波动很小；绕路的机器往往白天数据正常，一到晚上就开始丢包。

## 常见问题

### 低延迟VPS多少毫秒算合格？

看用户在哪。广东访问香港优质线路，10–30ms 属于正常水平，长三角 30–50ms；同样的物理距离下 ping 超过 100ms，大概率是绕路了。测试用 ping 加 traceroute，前者看往返时间，后者看路径。

### 为什么同一台香港VPS，白天很快晚上变卡？

晚高峰（北京时间 20 点到 23 点前后）国际出口拥堵，普通共享线路最先受影响。以走 CN2 GIA 的香港机器为例，白天 8–12ms、晚高峰 15–20ms 属于正常波动；晚上翻几倍的，就要怀疑线路等级了。

### 月付还是年付划算？

第一次用先月付或季付，确认线路符合预期再转年付。长期使用年付摊到每月明显更便宜，香港 CN2 GIA 入门档年付 $39.9，折合每月 $3.3 左右。试水阶段，季付 $19.9 的香港 Starter 档是个稳妥的中间选择。

### 流量用超了会停机吗？

看商家政策，差别很大。DMIT 东京线是限速不停机，超量后按套餐降到 50–500Mbps 继续跑；更多商家是直接停机。这条通常写在条款或帮助文档里，下单前翻一下。

### IP 被墙了怎么办？

换 IP 是常规操作，多数商家收费，LightNode 给每台机器两次免费更换。走 CN2 GIA 的机器被误伤的概率本身也低一些。
